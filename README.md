📍 Google Maps Live Location Tracking

A web-based Google Maps Live Location Tracking Application developed for the Institute of Management and Research (IMR), Jalgaon.

🚀 Live Demo: https://google-map.infinityfree.io/

🚀 Features
Google Maps Integration: Displays an interactive Google Map centered on IMR College, Jalgaon.
College Location Marker: Shows the college location with an information window.
Live Location Tracking: Tracks the user's real-time location using the browser's Geolocation API.
Distance Calculation: Calculates the distance between the user's current location and the college in kilometers.
Start Tracking: Starts live location tracking after permission is granted.
Stop Tracking: Stops location tracking whenever required.
Get Directions: Opens Google Maps directions to IMR College.
Responsive Design: Simple and user-friendly interface.

⚙️ Installation and Setup
1. Clone the Repository
bash
git clone https://github.com/sp0674774-ux/GoogleMap_Project.git

2. Navigate to the Project Directory
bash
cd GoogleMap_Project

3. Configure Google Maps API
Visit Google Cloud Console.
Create or select a project.
Enable Google Maps JavaScript API.
Generate an API key.
Configure API key restrictions.
Add your API key to the Google Maps script URL in index.html.

Note: Keep your API key secure and never expose an unrestricted key publicly.

4. Run the Project

Open index.html using VS Code Live Server or another local development server.

For live location tracking, use HTTPS or localhost and allow browser location permission.

💻 How to Use
Open the application in your browser.
View the IMR College location on Google Maps.
Click Start Live Location.
Allow browser location permission.
View your current location on the map.
Check the distance from IMR College.
Click Stop Tracking to stop location updates.
Click Get Directions to navigate to the college.
🔐 Permissions
Location access must be enabled.
The browser must support the Geolocation API.
HTTPS or localhost is required.
Users must grant location permission to enable tracking.
